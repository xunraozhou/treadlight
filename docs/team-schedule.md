# 《踏光：两拍回响》人员分工与活动安排

参赛成员：**严楷哲、沈语雯、李星莹**。队长：**严楷哲**。

## 一、人员分工与协作

### 1.1 团队组成与职责

团队成员为**严楷哲、沈语雯、李星莹**，由**严楷哲担任队长**。三人按程序与统筹、策划与视觉、音频测试与展示材料分工，共同完成最终验收。

以下为已经确认的职责安排及后续活动计划。现有成果包括可玩游戏、策划案、介绍视频、PPT、讲稿和游戏音画素材包；本阶段重点是实际试玩、内容复核、材料实名同步、版本统一与提交。

| 成员 | 职责定位 | 主要工作 | 负责交付 |
| --- | --- | --- | --- |
| **严楷哲** | **队长；程序、版本与统筹负责人** | 分配和跟进任务，维护游戏程序，修复问题，确定提交版本，组织最终审核与正式提交 | 稳定工程、Windows 可执行包、版本说明、最终提交目录及提交记录 |
| **沈语雯** | **策划、关卡与视觉交互负责人** | 维护玩法说明，检查关卡递进、教学与视觉辨识度，复核各材料中的规则和术语 | 更新后的策划案、体验问题与调整建议、经复核的教学和展示文案 |
| **李星莹** | **音频、测试与展示材料负责人** | 检查配乐及音画同步，组织试玩与复测，维护视频、PPT、讲稿及素材清单，安排计时排练 | 测试与复测记录、核验后的音画素材包和展示文件、排练计时及下载检查记录 |

### 1.2 严楷哲：队长、程序与版本统筹

1. **进度管理：** 汇总三人的待办事项，写明负责人、完成时间和验收条件。优先处理无法启动、无法通关、重试异常及文件缺失等影响交付的问题。
2. **程序维护：** 负责角色移动、节拍时钟、光桥状态、激光周期、计分和房间流程的维护，保证“起跳造路、落拍留光”的规则落实一致。
3. **问题修复：** 根据李星莹提供的设备信息和复现步骤定位问题；修复后说明影响范围，将新版本交回复测。
4. **参数协作：** 与沈语雯核对跳跃时间、桥前空间、安全平台和激光间歇。规则或参数发生变化时，同时通知更新策划、教学与展示文案。
5. **版本管理：** 确定最终工程版本，统一源码、可执行文件及包内说明。导出后提供明确的版本标记和改动记录，避免成员使用不同版本测试。
6. **材料汇总：** 接收沈语雯复核的策划案，以及李星莹核验的视频、宣讲和音画文件，整理成清晰的最终提交目录。
7. **正式提交：** 组织另外两位成员复核分享文件、下载权限和表单内容，负责完成百度网盘与指定表单提交，并保存分享地址和提交结果。
8. **现场支持：** 准备可运行游戏、离线备份和设备连接；现场负责运行演示及程序实现方面的问答。

### 1.3 沈语雯：玩法策划、关卡与视觉交互

1. **策划维护：** 复核已有完整策划案，保持玩法目标、规则、参数、关卡说明和当前实现一致；同步三位成员姓名与已确认的职责。
2. **关卡检查：** 逐间检查“唤醒余音、让光留下、接续回响”的教学顺序，确认桥前起跳空间、桥后落脚点和安全等待位置清楚可用。
3. **体验观察：** 结合试玩记录，找出玩家不理解造桥、没有意识到落拍固定或无法判断激光时机的位置，提出具体修改建议。
4. **视觉复核：** 检查临时青桥、固定金桥、预警虚线和危险光束的区别，确认角色落点、共鸣进度及出口状态清楚可见。
5. **交互文字：** 统一标题、教学、按键提示、判定反馈、失败和结算中的用语，避免重要提示遮挡角色或桥边。
6. **展示内容审核：** 对照实际游戏检查视频、PPT与讲稿，确认画面和口述准确解释四拍青桥、落拍留光及全部共鸣开门。
7. **修复验收：** 将问题位置、建议调整和完成标准交给严楷哲；更新后再次检查，记录是否解决原有理解或操作问题。
8. **现场协作：** 协助排练内容、计时与翻页衔接，准备作品立意、关卡安排和视觉设计方面的问答。

### 1.4 李星莹：音频、质量验证与展示材料

1. **声音检查：** 复核已有循环配乐的衔接、响度与音乐开关；与严楷哲共同检查扬声器和耳机环境下的判定感受、校准保存及暂停恢复。
2. **功能测试：** 检查启动、教学、三房间、失败重试、暂停继续、校准和最终结算，至少记录一次连续完整通关。
3. **设备验证：** 在干净解压目录及另一台 Windows 电脑上测试，记录设备、系统与版本，并检查中文、窗口显示、按键和音频输出。
4. **问题与复测记录：** 每条问题写明操作步骤、预期结果、实际结果和复现情况，必要时附截图或录像；收到修复版本后按相同步骤复测。
5. **视频复核：** 完整播放现有介绍视频，检查底部字幕、解说、音乐平衡和画面对应关系，确认成片不超过五分钟。
6. **宣讲材料维护：** 在已有 PPT 和讲稿中同步姓名、队长及分工，与沈语雯核对内容；组织完整试讲并记录实际时长，控制在三至五分钟。
7. **素材与文件整理：** 维护已经汇总的图标、截图、配乐及来源清单；游戏资源发生变化后同步更新素材包，并逐项检查文件可打开、压缩包可解压。
8. **提交前协助：** 协助严楷哲上传、下载和检查最终材料，确认取件人能够获取完整文件；保存核验结果供队长提交前复核。
9. **现场协作：** 按排练确定的方案组织宣讲材料，准备视频、PPT、讲稿和备用 PDF，协助音频与材料相关问答。

### 1.6 日常协作与现场配合

1. 每个活动日结束前，三人简短同步已完成事项、当前问题和下一步；由严楷哲更新统一待办。
2. 每项问题指定一名主负责人。涉及规则、声音或展示内容的改动，由对应成员复核后再合入提交版本。
3. 三人均需完整体验最终游戏，能够解释核心规则及各自负责部分。职责安排与已完成记录分开保存，实际成果以文件和复测结果为依据。
4. 现场配合建议为：李星莹主讲并管理展示材料，严楷哲负责设备和游戏演示，沈语雯协助计时、内容衔接及玩法问答。主讲与辅助顺序在完整排练时固定，避免临时切换影响三至五分钟的讲述节奏。
5. 团队名称、联系方式和登记所需身份信息由严楷哲汇总，成员逐项核对；资格与报名信息在正式提交前确认。
