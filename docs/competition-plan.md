# 《踏光：两拍回响》玩法策划与手册对照

本策划案对应《踏光：两拍回响》v0.2 可玩原型，依据《主题游戏创作大赛参赛手册》整理主题表达、玩法设计和材料进度。作品概览见[作品介绍](project-introduction.md)，完整提交待办见[参赛材料清单](submission-checklist.md)。

## 主题与立意

主题是“律动”。玩家进入沉寂的光之遗迹，以一段段“两拍起落”的动作修复道路。一次起跳只能换来暂时可走的光桥；完整地完成“随拍起跳—向前移动—落拍归位”，光才会留下。节奏由声音提示转化为世界状态和通关目标。

## 核心循环

1. 观察虚线桥与底部四拍灯，在桥前安全平台等待。
2. 随拍从地面起跳：准确 ±80 ms，良好 ±150 ms。成功后桥实体化四拍。
3. 保持方向输入；平地跳跃约两拍完成，落在光桥上时再次判定节拍。
4. 成功落拍：临时青桥变成永久金桥，点亮一个共鸣点，获得一次性 +120 光能。
5. 失败落拍：保留临时桥原有时限，可以从任一岸回跳修复；不扣除普通移动与跳跃能力。
6. 修复当前房间所有共鸣点，打开终点。激光只提供节奏压力，不替代修复目标。

普通与踩拍跳跃使用同一条运动轨迹；落拍不需要额外按键。无二段跳、冲刺、下砸或复杂组合键。同拍成功判定与同一桥的修复奖励均有去重。

## 和研究参考项目的可见区别

| 维度 | LIGHT//BOUND 研究参考 | 本项目 v0.2 |
| --- | --- | --- |
| 玩家目标 | 原项目说明以随音乐避开激光为主 | 修复道路、点亮全部共鸣点、抵达出口 |
| 节奏与世界的关系 | 主要编排音乐事件和激光 | 起跳造桥、落拍将桥永久化，直接决定道路与出口 |
| 空间组织 | 舞台生存结构 | 横向三个教学递进房间 |
| 新规则 | 不主张上游具有本版规则 | 有限青桥 → 落拍修复 → 永久金桥，含失败恢复路径 |
| 操作 | 原版有二段跳、下砸等动作 | 只保留左右移动与单次地面跳跃 |
| 画面和声音 | 上游素材仅供研究 | 代码绘制的几何遗迹、自定义图标、脚本合成音轨 |
| 工程 | 上游工程 | v0.2 运行代码只在 campaign/，无旧游戏/编辑器依赖 |

这里的创新是本作品相对于研究参考的具体玩法变化，不宣称这类机制在所有游戏中首次出现。

## 房间安排

- **唤醒余音**：无激光，学会在桥前起跳以及落拍留光。
- **让光留下**：同一规则加入有预警的横向激光，练习等拍与观察。
- **接续回响**：依次修复两段桥，完成全部共鸣后开门。

保持统一 120 BPM。平地跳跃约一秒，桥宽 200 px，水平速度 140 px/s；普通跳跃不能越过整段断桥。熟练自动路线约 18、20、25 秒，另有开场两秒准备。

## 建议的 3—5 分钟演示顺序

先用约 30 秒说明“律动如何修复遗迹”，随后演示第一段青桥、落拍后变金桥，再展示偏拍只能留下临时道路及两岸重试。最后演示激光预警、第三关双桥共鸣和终点开启。剩余时间展示统一时钟、判定去重、独立工程结构、测试证据与来源记录。
