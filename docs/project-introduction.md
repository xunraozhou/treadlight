# 《踏光：两拍回响》作品介绍

以下介绍对应当前 v0.2 可玩原型。团队名称、参赛者身份等信息应以实际报名信息填写。

## 一句话介绍

《踏光：两拍回响》是一款以“律动”为主题的 2D 节奏平台游戏：踩拍起跳生成临时光桥，两拍后踩拍落桥，将道路永久留下，点亮全部共鸣点并开启终点。

## 项目简介

《踏光：两拍回响》以“让短暂的光留下”为立意。玩家穿行于沉寂的光之遗迹，通过一段段有节奏的起跳与落地修复道路，让原本断开的空间重新连接。

游戏围绕“起跳造路、落拍留光”展开：玩家在节拍附近起跳，会唤醒一座持续四拍的青色光桥；保持向前，约两拍后踩拍落在桥面，光桥便会变为永久保留的金色道路，并点亮一个共鸣点。房间中的全部共鸣点修复后，出口才会开启。

音乐、节拍灯和角色光环共同帮助玩家判断时机；临时桥的时限与激光预警提供节奏压力，安全平台与两岸重试则保留等待和补救空间。普通跳跃始终可用，且与踩拍跳跃采用相同轨迹，便于玩家预判落点。

作品设置“唤醒余音”“让光留下”“接续回响”三个房间，依次引入光桥修复、激光预警和双桥共鸣。节奏贯穿动作、世界变化与通关条件，使“律动”成为玩家能够操作和观察到的规则。

当前原型使用 Godot 4.4.1 与 GDScript，已提供 Windows 可执行文件和工程源码，并完成三关流程、教学、判定、计分、暂停与重试。画面以代码绘制的几何遗迹构成，配有脚本合成的 120 BPM 试作音轨。

## 设计特点

| 设计 | 玩家体验 | 与“律动”的关联 |
| --- | --- | --- |
| 两拍起落 | 起跳后能够预判落地时机 | 一个完整动作形成节奏单元 |
| 青桥变金桥 | 每次成功修复都留下可见结果 | 节拍改变道路的持续状态 |
| 共鸣点开门 | 修复结果构成明确目标 | 通关依赖节奏动作的完成 |
| 安全平台与两岸补救 | 可等待、观察和重试 | 鼓励学习节拍，减少失误后的无效重复 |
