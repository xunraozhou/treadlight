# 踏光：两拍回响

**起跳造路，落拍留光。**

《踏光：两拍回响》是一款将音乐节拍与道路修复结合的 2D 节奏平台游戏。玩家穿行于沉寂的光之遗迹，用一段段有节奏的起跳与落地，让断开的道路重新连接。

## 让短暂的光留下

在节拍附近起跳，会唤醒一座持续四拍的青色光桥。保持向前，约两拍后踩拍落在桥面，光桥便会变为永久保留的金色道路，并点亮一个共鸣点。房间中的全部共鸣点修复后，出口才会开启。

一次起跳创造通路，一次落地将它留下。游戏通过青桥到金桥的变化，把成功的节奏动作转化为可见的空间进展。

## 在等待与前进之间

音乐、四拍灯和角色光环共同提示下一拍。普通跳跃始终可用，与踩拍跳跃采用相同轨迹；落地自动判定，无需额外按键。

安全平台允许玩家停留、观察与等待。落拍失败后，可以从桥的任一岸重新尝试。激光以提前一拍的预警带来危险，玩家需要在修复道路的同时，选择继续前进或等待合适的时机。

## 从第一声余音到终点

“唤醒余音”让玩家在没有激光干扰的环境里学会造桥与留光；“让光留下”加入有预警的激光；“接续回响”要求依次修复两段光桥，完成全部共鸣后抵达出口。

深色几何遗迹、青色临时桥与金色永久桥构成主要视觉语言。随着道路被修复，空间逐渐恢复色彩。统一的 120 BPM 音乐让声音、动作与机关保持一致的时间关系。
