# 踏光：两拍回响 / Treadlight

**起跳造路，落拍留光。**

《踏光：两拍回响》是一款围绕“律动”主题设计的 2D 节奏平台游戏。玩家穿行于沉寂的光之遗迹，在节拍中起跳，唤醒短暂的青色光桥；再用一次踩准节拍的落地，把光桥修复为永久的金色道路。点亮全部共鸣点，才能开启通往下一个房间的出口。

**主题游戏创作大赛作品原型 · 当前可玩版本 v0.2 · Windows x64 · Godot 4.4.1 / GDScript**

## 作品立意与主题表达

本作以“让短暂的光留下”为立意：玩家通过完整的起跳与落地，将一段暂时可以通行的道路修复为可持续使用的归途。青桥到金桥的变化，让每次成功的节奏动作都能在场景中留下可见结果。

“律动”贯穿声音、动作与关卡目标。120 BPM 的音乐提供节拍，四拍指示灯和角色光环帮助预判；起跳与落地分别触发道路生成和永久修复，修复结果决定出口是否开启。

作品的主要设计特点：

- **一次起落，两次回应**：踩拍起跳造桥，约两拍后踩拍落桥留光，让跳跃形成可预判的节奏单元。
- **从临时通路到永久道路**：四拍青桥带来时限，成功落拍后变成金桥，并点亮共鸣点。
- **允许等待与补救**：普通跳跃始终可用。落拍失败后，可以从桥的任一岸重新尝试；安全平台提供等拍空间。
- **三个房间逐步教学**：先学会修复，再观察激光预警，最后接续两段光桥，完成全部共鸣后通关。

## 快速试玩

1. 在 [v0.2 发布页](https://github.com/xunraozhou/treadlight/releases/tag/v0.2.0) 下载 `Treadlight-v0.2-Windows-x64.zip`。
2. 完整解压文件夹，保持 `Treadlight.exe` 与 `Treadlight.pck` 位于同一目录。
3. 双击 `Treadlight.exe`，在标题页选择“开始旅程”；首次游玩可先阅读“玩法 / 两拍回响”。无需安装 Godot。

需要查看工程时，可下载同页的 `Treadlight-v0.2-source.zip`，用 Godot 4.4.1 Standard 导入 `project.godot`，按 F5 运行。发布包中的源码对应 v0.2 快照，仓库主页提供最新项目说明。

## 核心玩法

| 环节 | 操作 | 结果 |
| --- | --- | --- |
| 起跳造路 | 在虚线光桥附近，随节拍从地面起跳 | 生成持续四拍的青桥，最后一拍闪烁 |
| 落拍留光 | 保持向前，约两拍后踩拍落在桥面 | 修复为永久金桥，点亮一个共鸣点 |
| 失误补救 | 未能落拍留光时，从任一岸重新起跳落桥 | 再次尝试修复；青桥仍按原有时限消失 |
| 共鸣开门 | 修复当前房间的全部光桥 | 出口开启，抵达后进入下一间 |

| 起跳造路：四拍临时青桥 | 落拍留光：永久金桥 |
| --- | --- |
| ![实际起跳触发的临时青桥](docs/gameplay.png) | ![同一次起落修复后的永久金桥](docs/restored.png) |

普通跳跃与踩拍跳跃使用相同轨迹；落地自动判定，无需额外按键。准确判定为节拍前后 80 ms 以内，良好判定为 150 ms 以内，两者都可造桥和留光。激光提前一拍以金色虚线预警，粉色实体光束危险一拍，可以等待或起跳越过。

准确起跳获得 100 光能，良好起跳获得 60 光能，每座桥首次修复获得 120 光能。同拍成功判定与同桥修复奖励均去重。失败重试会重置本房间的时钟、机关和分数，保留先前已通关房间的累计光能。

## 操作方式

| 按键 | 功能 |
| --- | --- |
| A / D、← / → | 左右移动 |
| 空格、W、↑ | 地面起跳 |
| Enter | 开始、失败重试、过关继续 |
| R | 当前房间重试 |
| Esc | 暂停或继续；结果页、帮助页返回标题 |
| [ / ] | 每次减少或增加 10 ms 判定校准，范围 ±250 ms，自动保存 |
| M | 音乐开关 |

开场有四拍准备。不同声卡、耳机与显示设备可能需要校准；正校准值表示接受稍晚于音乐节拍的输入。

## 关卡设计

| 房间 | 玩家需要掌握的内容 | 已验证的自动路线用时 |
| --- | --- | --- |
| 唤醒余音 | 无激光，学习起跳造路与落拍留光 | 约 18 秒 |
| 让光留下 | 修复道路，同时观察一种横向激光的预警 | 约 20 秒 |
| 接续回响 | 依次修复两段桥，全部共鸣后开启终点 | 约 25 秒 |

上述用时不含两秒开场准备，是自动路线的验证结果；首次真人游玩的用时会受等待和重试影响。

## 技术实现与验证

游戏使用 Godot 4.4.1 Standard 与 GDScript。音乐、判定、光桥、激光和提示读取统一时钟，并补偿混音等待与音频输出延迟。运行逻辑位于 `campaign/`；几何画面由代码绘制，试作音轨由 Python 标准库合成。

[开发与验证说明](docs/development.md)列出工程结构、测试命令、判定参数和检查范围。[GitHub Actions](https://github.com/xunraozhou/treadlight/actions)提供自动验证记录。
